# maze-solver
maze solver app. gets a maze from "maze.txt" file and stores output in "solved.txt" file
# input format
 1 : wall
 0 : free space
 s : start point
 e : end point
# Features 
 . stores free spaces in a graph
 . uses Depth First Search graph search to find the way
